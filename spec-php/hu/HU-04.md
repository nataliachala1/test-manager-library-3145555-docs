# HU-04 · Buscar libros

## Identificación y objetivo original
HU-04 · Buscar libros. Actor autenticado admin o librarian. Encontrar libros activos por texto y categoría.

## Descripción y criterios originales
Buscar coincidencias parciales de título/autor, filtrar categoría y obtener resultados ordenados por título, paginados y con total.

- **CA-04.1** Búsqueda por texto parcial en título o autor, filtro por categoría, solo libros activos, orden por título, paginada (`page`, `size`, máx. 50).
- **CA-04.2** La respuesta incluye el total de resultados.
- **CA-04.3** Consultar un libro por id inexistente o dado de baja: 404.

## Reglas, contrato y datos
Solo catálogo activo; size máximo 50. Entradas q, category_id, page, size; detalle UUID. Salida paginada con libro, página, tamaño y total. Endpoints GET /api/v1/books y GET /api/v1/books/{id}. Entidades book y category.

## Dependencias, tareas, pruebas y aceptación
Depende de HU-03. Responsables: api (consulta/persistencia), app (búsqueda/presentación). Tareas T-08, T-12, T-16, T-22; RNF-1 se mide aparte con 5 000 libros.
- CA-04.1: coincidencias parciales, filtro categoría, excluir dados de baja, ordenar y paginar máximo 50.
- CA-04.2: total del resultado filtrado.
- CA-04.3: detalle inexistente/dado de baja da 404.
Evidencia de consulta/contrato; medición RNF-1 requiere procedimiento DT-005.
