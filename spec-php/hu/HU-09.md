# HU-09 · Libros vencidos

## Identificación y objetivo original
HU-09 · Libros vencidos. Actores admin y librarian. Consultar líneas sin devolución y vencidas.

## Descripción y criterios originales
Mostrar datos operativos: libro, socio y días de retraso, ordenados desde el mayor retraso.

- **CA-09.1** Lista las líneas sin devolver con `due_at` anterior a ahora: libro, socio, días de retraso.
- **CA-09.2** Ordenadas por más días de retraso primero. Solo `admin` y `librarian`.

## Reglas, contrato y datos
Vencido: returned_at nulo y due_at anterior al instante actual; days_late calculado, no columna. Esta lista muestra socio; HU-10 no. Entrada page/size; salida loan_id, item_id, book_title, member_name, due_at, days_late, paginada. Endpoint GET /api/v1/loans/overdue. Entidades loan_item, loan, member.

## Dependencias, tareas, pruebas y aceptación
Depende de HU-06; HU-07 quita líneas al devolverlas. Responsables: api (consulta), app (vista), tool (demo solo con estrategia aprobada). Tareas T-10, T-13, T-16, T-21, T-22; DT-008 bloquea evidencia demo actual.
- CA-09.1: incluir línea no devuelta vencida con datos; excluir devuelta/no vencida.
- CA-09.2: ordenar por retraso descendente; rol no permitido da 403.
Evidencia con reloj/datos controlados de límite temporal, campos, orden y roles. Tres vencidos demo requiere cerrar DT-008.
