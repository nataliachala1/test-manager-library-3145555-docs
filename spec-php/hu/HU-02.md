# HU-02 · Dar de alta bibliotecarios

## Identificación y objetivo original
HU-02 · Dar de alta bibliotecarios (admin). Actor Administrador. Crear cuentas de bibliotecario con nombre, clave y rol permitido.

## Descripción y criterios originales
El admin autenticado registra un usuario librarian. El nombre se normaliza y es único; no se crea otro admin.

- **CA-02.1** El admin crea un usuario con nombre, clave y rol `librarian`.
- **CA-02.2** El nombre de usuario se guarda en minúsculas y recortado; es único. Repetido: 409.
- **CA-02.3** Pedir el rol `admin` por la API responde 422. La clave nunca se devuelve ni se registra en logs.

## Reglas, contrato y datos
El admin inicial viene del entorno; no se otorga en ejecución. Entrada username/password/role librarian; salida id, username normalizado, role, sin clave/hash. Endpoint POST /api/v1/users, admin; USERNAME_TAKEN 409 y VALIDATION_ERROR 422. Entidad user (id, username, password_hash, role).

## Dependencias, tareas, pruebas y aceptación
Depende de HU-01. Responsables: api (caso de uso, persistencia, seguridad); app (operación admin). Tareas T-06, T-07, T-12, T-14, T-16.
- CA-02.1: admin crea librarian.
- CA-02.2: «Ana » queda ana; repetir username normalizado da 409.
- CA-02.3: rol admin da 422; clave/hash no aparece en respuesta/logs.
Evidencia de caso de uso, unicidad persistida, autorización y ausencia de secretos (RNF-3).
